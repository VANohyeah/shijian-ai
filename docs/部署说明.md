# 部署说明

> 给「把食鉴放到公网上」用。两种方式：Docker（推荐）或直接用 Node 跑。

## 一、前置

- 一台能装 Docker 的 Linux 服务器（1 核 1 G 足够，识图是调 API，不吃本地算力）
- 一个可用的智谱 API Key（`GLM_API_KEY`）
- 一个域名（可选，没有就用 `IP:端口` 访问）

## 二、Docker 方式（推荐）

```bash
git clone https://github.com/VANohyeah/shijian-ai.git
cd shijian-ai

# 写环境变量
cat > .env <<'EOF'
GLM_API_KEY=你的key
GLM_BASE_URL=https://open.bigmodel.cn/api/paas/v4
GLM_TEXT_MODELS=glm-4-flash,glm-5.3-flash
GLM_VISION_MODELS=glm-4v-plus-0111,glm-4v-flash
EOF

docker build -t shijian .
docker run -d --name shijian \
  --env-file .env \
  -p 3000:3000 \
  -v $(pwd)/data:/app/data \
  --restart unless-stopped \
  shijian
```

**`-v $(pwd)/data:/app/data` 不能省**：收藏、历史、档案都存在这个目录，不挂卷容器一删就全没了。

## 三、Node 直接跑

```bash
npm ci
npm run build
node .output/server/index.mjs
```

用 systemd 托管：

```ini
[Unit]
Description=shijian
After=network.target

[Service]
WorkingDirectory=/opt/shijian
EnvironmentFile=/opt/shijian/.env
ExecStart=/usr/bin/node .output/server/index.mjs
Restart=always

[Install]
WantedBy=multi-user.target
```

## 四、Nginx 反代

见 `deploy/nginx.conf.example`。**注意 `/api/chat` 必须关掉 `proxy_buffering`**，否则流式输出会变成一次性蹦出全文。

## 五、部署后自检（5 分钟）

```bash
# 1. 服务在不在、模型通不通
curl http://你的地址/api/health
# 期望：{"ok":true,...,"ready":true}
```

浏览器逐项验收：

| 检查 | 期望 |
|---|---|
| `/` | 首页两个入口，不报错 |
| `/scan` | 传一张菜单图，10 秒内出菜品卡，带 ✅/⚠️/⛔ |
| `/cities` | 30 个城市分 7 个赛区 |
| `/city/chengdu` | 9 道菜，都带判定 |
| `/dish/dish_chengdu_01` | 语言视角与复刻视角都有内容 |
| `/profile` | 改一个过敏原 → 保存 → 刷新仍在 |
| `/chat` | 输入问题，文字逐字出现 |
| `/favorites` | 收藏与历史能显示 |

**评委体验路径**：首页 → 拍菜单 → 点某道菜 → 回首页 → 找地方菜 → 配一桌。这条路径必须全程无报错。

## 六、常见问题

| 现象 | 原因 |
|---|---|
| `ready: false` | `.env` 没被读到，或容器没传 `--env-file` |
| 识图 502 | Key 无效 / 余额不足，看接口返回的 `statusMessage` |
| 收藏刷新就没了 | 没挂 `data` 卷 |
| 流式变一次性 | Nginx 缓冲没关 |
| 部署后很慢但本地正常 | 服务器到智谱的出网带宽差，换机房或加代理 |

## 七、成本

识图一次约 1k tokens（`glm-4v-plus` 4 元/百万 tokens），折合**约 0.004 元/次**。演示阶段几十块钱足够。
