# 录屏操作清单（对着点就行）

> 用途：录 5–8 分钟演示视频时照着点，避免现场找按钮。
> 建议：录屏前先跑一遍熟手，第二遍再正式录。

## 录屏前准备

1. `npm run dev` 起来，浏览器开 `http://localhost:3000`
2. **把档案填好再录**：`/profile` → 勾上「甲壳类」「花生」+「痛风」+ 目标「减脂」→ 保存
   （有档案才有红黄绿，空档案录出来全是绿色，没戏）
3. 准备一张清晰的菜单图放桌面（比萨菜单、中餐菜单各一张更好）
4. 浏览器缩放调到 100%，关掉书签栏和无关标签
5. 录屏软件 1080p，帧率 30 即可

## 分镜与点击路径

| # | 画面 | 操作 | 旁白要点 |
|---|---|---|---|
| 1 | 首页 | 停在 `/` | 「吃饭前最常问的一句话是：这道菜我能不能吃」 |
| 2 | 首页 | 指两个入口 | 「两条入口：拍菜单，或者直接找地方菜」 |
| 3 | 档案 | 点右上「我」→ `/profile` | 「先填一次档案：过敏、慢病、目标」 |
| 4 | 档案 | 勾「甲壳类」「花生」「痛风」 | 「填一次，之后每次判断都用它」 |
| 5 | 档案 | 点「保存档案」 | 「存下来，刷新也在」 |
| 6 | 拍菜单 | 点导航「拍菜单」→ `/scan` | 「拍一张菜单」 |
| 7 | 拍菜单 | 选图，等 5–15 秒 | 「模型在看图，通常十秒左右」 |
| 8 | 结果 | 停在结果区 | 「识别出 8 道，每道都有结论」 |
| 9 | 结果 | 指红色的那道 | 「这道含虾，我甲壳类过敏，直接标红」 |
| 10 | 结果 | 指黄色的那道 | 「这道高汤，痛风要限制，标黄不是不能吃」 |
| 11 | 结果 | 点某道菜的「改」 | 「识别错了可以手改，改完立刻重新判定」 |
| 12 | 结果 | 改一个食材，点保存 | 「比如把五花肉改成鸡胸，结论会变」 |
| 13 | 详情 | 点菜名进 `/dish/[id]` | 「点进来看这道菜到底是什么」 |
| 14 | 详情 | 切到「复刻视角」tab | 「还有家常做法」 |
| 15 | 详情 | 滚到「过敏替代」 | 「这是最值钱的部分：我这情况该怎么换料」 |
| 16 | 城市 | 点导航「找地方菜」→ `/cities` | 「换个场景：不拍照，直接选城市」 |
| 17 | 城市 | 点「成都」→ `/city/chengdu` | 「进来就已经标好了——不用拍、不用问」 |
| 18 | 城市 | 停在判定区 | 「9 道菜，哪些能吃一眼看完」 |
| 19 | 配菜 | 填 3 人 / 200 元 → 「帮我配一桌」 | 「告诉我人数和预算，自动配一桌」 |
| 20 | 配菜 | 停在结果 | 「不能吃的自动剔除，总价不超预算」 |
| 21 | 对话 | 点导航「问食鉴」→ `/chat` | 「也可以直接问」 |
| 22 | 对话 | 输入「我海鲜过敏痛风，水煮鱼能吃吗」 | 「它会结合我刚才填的档案回答」 |
| 23 | 对话 | 等流式输出 | 「注意字是逐字出来的，不是等完才蹦」 |
| 24 | 我的 | 点「我的」→ `/favorites` | 「刚才看过的都留了记录」 |
| 25 | 我的 | 指收藏 | 「觉得不错可以收藏」 |
| 26 | 收尾 | 回首页 | 「食鉴不告诉你哪家好吃，告诉你自己能不能吃」 |

## 录完检查

- [ ] 全片 5–8 分钟（不够就把 10–12 秒的识别等待剪掉一部分）
- [ ] 1080p，普通话讲解
- [ ] 没有出现 API Key、终端里的密钥
- [ ] 每屏都能看清字（缩放别太小）
- [ ] 片头 3 秒内出现项目名

## 常见翻车点

| 问题 | 处理 |
|---|---|
| 识别等太久冷场 | 提前把图传好一次再录，或后期剪掉等待 |
| 忘了填档案，结果全绿 | 录前必做第 2 步 |
| 网络抖，识图失败 | 重录这一段；或换手机热点 |
| 字体太小 | 浏览器缩放 110%，或后期局部放大 |
