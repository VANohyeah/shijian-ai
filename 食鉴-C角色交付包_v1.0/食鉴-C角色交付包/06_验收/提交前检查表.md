## 三、常见翻车点（提前避）

| 翻车点 | 后果 | 预防 |
|---|---|---|
| 仓库是 Private | 直接不合规 | 提交前用无痕窗口打开 |
| Git 历史只有 1 个提交 | 扣"真实开发过程"分 | 每天提交，别攒到最后 |
| 视频超过 8 分钟 | 可能被截断评审 | 剪辑时卡 7:10，留余量 |
| 文档 40 页 | 超页数要求 | 导出后立刻数页，砍附录 |
| `.env` 进了仓库 | 安全分直接崩 | 提交前全局搜 `sk-`、`API_KEY` |
| demo 演示账号没数据 | 评审看到空页面 | 提前准备演示账号 |
| 视频里有真实手机号 | 隐私问题 | 录屏前开勿扰、用小号 |
